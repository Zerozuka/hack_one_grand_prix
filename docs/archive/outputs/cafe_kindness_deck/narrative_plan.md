# 「小さくなる日本」からつなげる5枚スライド

## Audience
ハッカソン初期発表を聞く審査員・参加者。実装詳細よりも、問題意識・着眼点・提案の方向性を短時間で理解してもらう。

## Objective
「小さくなる日本」という表題から、人口減少だけでなく感謝やつながりの表現機会も小さくなっている、という視点を提示する。日本人の内気さを否定せず、内気なままでも感謝を伝えられる仕組みとして、カフェ空間への匿名リアクションアプリを印象づける。

## Narrative Arc
1. 日本は人口だけでなく、つながりも小さくなっている。
2. 日本人は感謝を思っていても、口に出すのが苦手。
3. 問題は優しさがないことではなく、出し方がないこと。
4. 匿名でもよいから、感謝を空間に残す。
5. 内気なままでも優しさが伝わる世界を目指す。

## Slide List
1. 小さくなる日本: 人口だけでなく、人とのつながりも小さくなっている。
2. 注目したこと: 日本人は、感謝を思っていても口に出すのが苦手だ。
3. 本質的な課題: 優しさはある。でも、出し方がない。
4. 提案: 匿名でもいいから、感謝を空間に残せるようにする。
5. 目指す世界: 内気なままでも、優しさは伝えられる。

## Visual System
16:9、編集可能なテキスト中心。背景は淡いカフェ照明・余白・小さな反応粒子をイメージした抽象的なPowerPoint図形で構成する。色は暗い墨色、温かい白、柔らかい緑、控えめな橙を使い、重すぎないが社会課題の導入にも耐える雰囲気にする。

## Editability Plan
全ての本文・見出し・補足はPowerPoint上で編集可能なテキストオブジェクトにする。背景・装飾・リアクションモチーフも図形で構成し、後から色や位置を調整できるようにする。
