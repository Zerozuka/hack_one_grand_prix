## 人と人を動的に繋げるアプリ

インターネットの普及に伴い, 人との繋がりは簡単になった. 一方で, 以前としてその敷居は高いのではないか？

従来では人と実際にスケージュールするのが難しかった -> インターネットというフィールドではいつでも繋がれるようになった
しかし.
繋がれるようにはなったもののみんなそれを用いてつながりを持っているわけではない. なぜだろうか？

繋がれるようになってもそれを企画しなければいけない. 何をやるのか決めなければならない. 日時, 集合場所も決めなければならない. 
=> あまり繋がろうと思わない. (実際僕も現実でしかやったことない.)

X や Line とかでコミュニケーションはできてもそれらを実際にやるためには別の場所で誰か個人がやらなければいけない. 中央集権的だったがそれを　AI が担うことであたかも P2P のようになる.
