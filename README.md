# Connect Graph App

`Connect Graph` は、コミュニティの関係性を可視化しながら、
責任者画面とユーザー画面をログインで切り替えて試せるフロントエンドアプリです。

## 今回やったこと

- 固定デモ用のハードコード状態から、`data/demo-data.json` 読み込みに変更
- `localStorage` に保存して、編集内容がリロード後も残るように変更
- 責任者アカウントとユーザーアカウントを分け、ログイン画面を追加
- 責任者はコミュニティ全体の編集、ユーザーは自分向けの推薦確認とプロフィール更新ができるように変更
- GPS 依存を外して、興味・目的・活動タグだけで動くように変更

## 起動方法

このアプリは `JSON` を `fetch()` で読むため、`file://` ではなく HTTP 経由で開くのを前提にしています。

### Docker

```bash
docker compose up --build
```

起動後:

```text
http://localhost:8080
```

停止:

```bash
docker compose down
```

## できること

- ログインによる責任者画面 / ユーザー画面の切り替え
- コミュニティ切り替え
- メンバー検索
- ユーザー選択
- プロフィール編集
- ダミーユーザー追加
- 関係性追加 / 削除
- 推薦モード切り替え
- グラフ、分析、推薦のリアルタイム更新
